# Get Conditional Order by ID

`GET` https://api.dhan.co/v2/alerts/orders/{alertId}

Retrieve status and details for a specific conditional order.

Retrieve the status and details of a specific conditional order by its unique identification (alertId).

Returns a conditional order with its status, the condition it watches and the orders it will place.

**Before you start with Get Conditional Order by ID API**

1. Generate an access token on [web.dhan.co](https://web.dhan.co) under **Profile → Trading & Data APIs**.
2. Copy the `alertId` from [Get All Conditional Orders](/api/v2/conditional-triggers/get-all-conditional-triggers) and enter it under Path Parameters below.

## Sample request for Get Conditional Order by ID API

Fetch one conditional order. Replace the alert ID (`1100000123` here) and access token with your own.

```bash title="cURL"
curl --request GET \
  --url https://api.dhan.co/v2/alerts/orders/1100000123 \
  --header 'access-token: <your-access-token>'
```

### Path Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| alertId | string | Yes | Alert specific identification generated by Dhan |


### Status Codes

| Code | Description |
|------|-------------|
| 200 | Conditional trigger details |
| 401 | Unauthorized |


### Example Request

```bash
curl -X GET https://api.dhan.co/v2/alerts/orders/{alertId} \
  -H "access-token: <your-access-token>"
```
