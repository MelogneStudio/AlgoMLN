# Delete Conditional Order

`DELETE` https://api.dhan.co/v2/alerts/orders/{alertId}

Delete an existing conditional order.

Cancel a conditional order before its condition is met, using its `alertId`.

**Before you start with Delete Conditional Order API**

1. Generate an access token on [web.dhan.co](https://web.dhan.co) under **Profile → Trading & Data APIs**.
2. Whitelist your [static IP](/api/v2/authentication/set-ip). Orders only go through from it.
3. Copy the `alertId` from [Get All Conditional Orders](/api/v2/conditional-triggers/get-all-conditional-triggers) and enter it under Path Parameters below.

> **NOTICE:** Order Placement, Modification and Cancellation APIs requires Static IP whitelisting - [refer here](/api/v2/authentication#setup-static-ip)

## Sample request for Delete Conditional Order API

Delete a conditional order. There is no request body. Replace the alert ID (`1100000123` here) and access token with your own.

```bash title="cURL"
curl --request DELETE \
  --url https://api.dhan.co/v2/alerts/orders/1100000123 \
  --header 'access-token: <your-access-token>'
```


## Sample response for Delete Conditional Order API

```json title="200 OK"
{
  "alertId": "1100000123",
  "alertStatus": "CANCELLED"
}
```

Check the [Annexure](/api/v2/annexure#trading-api-error) for error codes.


### Path Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| alertId | string | Yes | Alert specific identification generated by Dhan |


### Response Fields

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| alertId | string | No | Alert specific identification generated by Dhan |
| alertStatus | enum string | No | Last updated alert status [see annexure](/api/v2/annexure#status) Values: `ACTIVE`, `TRIGGERED`, `EXPIRED`, `CANCELLED`. |


### Status Codes

| Code | Description |
|------|-------------|
| 200 | Conditional trigger deleted |
| 401 | Unauthorized |


### Example Request

```bash
curl -X DELETE https://api.dhan.co/v2/alerts/orders/{alertId} \
  -H "access-token: <your-access-token>"
```
