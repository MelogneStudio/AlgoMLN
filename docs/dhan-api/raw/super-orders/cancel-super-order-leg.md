# Cancel Super Order Leg

`DELETE` https://api.dhan.co/v2/super/orders/{order-id}/{order-leg}

Cancel a specific leg of a super order.

Users can cancel a pending/active super order using the order ID. There is no body for request and response for this call. On successful completion of request ‘202 Accepted’ response status code will appear.

**Before you start with Cancel Super Order Leg API**

1. Generate an access token on [web.dhan.co](https://web.dhan.co) under **Profile → Trading & Data APIs**.
2. Whitelist your [static IP](/api/v2/authentication/set-ip). Orders only go through from it.
3. Copy the `orderId` from the [super order book](/api/v2/super-orders/get-super-orders) and pick the leg to cancel under Path Parameters below.

> **NOTICE:** Order Placement, Modification and Cancellation APIs requires Static IP whitelisting - [refer here](/api/v2/authentication#setup-static-ip)

## Sample request for Cancel Super Order Leg API

Cancel the target leg of a Super Order. There is no request body. Replace the order ID (`112111182198` here) and access token with your own, and pick the leg to cancel.

```bash title="cURL"
curl --request DELETE \
  --url https://api.dhan.co/v2/super/orders/112111182198/TARGET_LEG \
  --header 'access-token: <your-access-token>'
```


## Sample response for Cancel Super Order Leg API

Values are illustrative.

```json title="200 OK"
{
  "orderId": "112111182198",
  "orderStatus": "CANCELLED"
}
```

Check the [Annexure](/api/v2/annexure#trading-api-error) for error codes.


### Path Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| order-id | string | Yes | Order ID of the Order being cancelled |
| order-leg | string | Yes | Order Leg to be cancelled Values: `ENTRY_LEG`, `TARGET_LEG`, `STOP_LOSS_LEG`. |


### Response Fields

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| order-id | string | No | Order specific identification generated by Dhan |
| orderStatus | enum string | No | Last updated order status [see annexure](/api/v2/annexure#order-status) Values: `TRANSIT`, `PENDING`, `REJECTED`, `CANCELLED`, `PART_TRADED`, `TRADED`, `EXPIRED`, `MODIFIED`, `TRIGGERED`. |


### Status Codes

| Code | Description |
|------|-------------|
| 200 | Leg cancelled |


### Example Request

```bash
curl -X DELETE https://api.dhan.co/v2/super/orders/{order-id}/{order-leg} \
  -H "access-token: <your-access-token>"
```
