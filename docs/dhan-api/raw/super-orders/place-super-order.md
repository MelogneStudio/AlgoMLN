# Place Super Order

`POST` https://api.dhan.co/v2/super/orders

Place a bracket order with entry, target, and stop-loss levels.

A Super Order is a bracket order: a collection of orders placed as a single order request, made up of an entry leg, a target leg and a stop loss leg, with the option to add a trailing stop loss.

With Super Orders you can:

- Place the entry, target and stop loss legs together in one request.
- Add a trailing stop loss using `trailingJump`.
- [Modify](/api/v2/super-orders/modify-super-order) any leg while the order is in `PENDING` or `PART_TRADED` state.
- [Cancel](/api/v2/super-orders/cancel-super-order-leg) a leg.
- [Retrieve](/api/v2/super-orders/get-super-orders) all your Super Orders.

**Before you start with Place Super Order API**

1. Generate an access token on [web.dhan.co](https://web.dhan.co) under **Profile → Trading & Data APIs**.
2. Whitelist your [static IP](/api/v2/authentication/set-ip). Orders only go through from it.
3. Look up the `securityId` and `exchangeSegment` in the [instrument list](/api/v2/instruments).
4. Set the entry `price`, `targetPrice` and `stopLossPrice`.

> **NOTICE:** Order Placement, Modification and Cancellation APIs requires Static IP whitelisting - [refer here](/api/v2/authentication#setup-static-ip)

## Sample request for Place Super Order API

Buy 1 share of Vodafone Idea (`securityId` 14366) at ₹13.00 with a ₹14.00 target, a ₹12.50 stop-loss and a ₹0.10 trailing jump. Replace the client ID and access token with your own.

```bash title="cURL"
curl --request POST \
  --url https://api.dhan.co/v2/super/orders \
  --header 'Content-Type: application/json' \
  --header 'access-token: <your-access-token>' \
  --data '{
    "dhanClientId": "<your-client-id>",
    "correlationId": "dhan-docs-test",
    "transactionType": "BUY",
    "exchangeSegment": "NSE_EQ",
    "productType": "CNC",
    "orderType": "LIMIT",
    "securityId": "14366",
    "quantity": 1,
    "price": 13,
    "targetPrice": 14,
    "stopLossPrice": 12.5,
    "trailingJump": 0.1
  }'
```


## Sample response for Place Super Order API

Values are illustrative.

```json title="200 OK"
{
  "orderId": "112111182198",
  "orderStatus": "PENDING"
}
```

Check the [Annexure](/api/v2/annexure#trading-api-error) for error codes.


### Request Body Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| dhanClientId | string | Yes | User specific identification generated by Dhan |
| correlationId | string | No | User/partner generated id for tracking back. Constraints: Max 30 chars, Allowed: a-zA-Z0-9-_. |
| transactionType | enum | Yes | The trading side of transaction Values: `BUY`, `SELL`. |
| exchangeSegment | enum | Yes | Exchange Segment (see Annexure) Values: `NSE_EQ`, `NSE_FNO`, `NSE_COMM`, `BSE_EQ`, `BSE_FNO`, `MCX_COMM`. |
| productType | enum | Yes | Product type (see Annexure) Values: `CNC`, `INTRADAY`, `MARGIN`, `MTF`. |
| orderType | enum | Yes | Order Type Values: `LIMIT`, `MARKET`. |
| securityId | string | Yes | Exchange standard ID for each scrip. refer here |
| quantity | int | Yes | Number of shares for the order |
| price | float | Yes | Price at which order is placed |
| targetPrice | float | Yes | Target Price for the Super Order |
| stopLossPrice | float | Yes | Stop Loss Price for the Super Order |
| trailingJump | float | Yes | Price Jump by which Stop Loss should be trailed |


### Response Fields

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| orderId | string | No | Order specific identification generated by Dhan |
| orderStatus | enum string | No | Last updated order status [see annexure](/api/v2/annexure#order-status) Values: `TRANSIT`, `PENDING`, `REJECTED`, `CANCELLED`, `PART_TRADED`, `TRADED`, `EXPIRED`, `MODIFIED`, `TRIGGERED`. |


### Status Codes

| Code | Description |
|------|-------------|
| 200 | Super order placed |


### Example Request

```bash
curl -X POST https://api.dhan.co/v2/super/orders \
  -H "access-token: <your-access-token>" \
  -H "Content-Type: application/json"
```
