# Convert Position

`POST` https://api.dhan.co/v2/positions/convert

Convert position between product types (e.g., INTRADAY to CNC).

Users can convert their open position from intraday to delivery or delivery to intraday.

**Before you start with Convert Position API**

1. Generate an access token on [web.dhan.co](https://web.dhan.co) under **Profile → Trading & Data APIs**.
2. Whitelist your [static IP](/api/v2/authentication/set-ip). Orders only go through from it.
3. Pick an open position from [Get Positions](/api/v2/portfolio/get-positions) and enter its `securityId` and quantity.

> **NOTICE:** Order Placement, Modification and Cancellation APIs requires Static IP whitelisting - [refer here](/api/v2/authentication#setup-static-ip)

## Sample request for Convert Position API

Convert 1 share of an intraday Vodafone Idea (`securityId` 14366) long position to delivery. Replace the client ID and access token with your own.

```bash title="cURL"
curl --request POST \
  --url https://api.dhan.co/v2/positions/convert \
  --header 'Content-Type: application/json' \
  --header 'access-token: <your-access-token>' \
  --data '{
    "dhanClientId": "<your-client-id>",
    "fromProductType": "INTRADAY",
    "exchangeSegment": "NSE_EQ",
    "positionType": "LONG",
    "securityId": "14366",
    "convertQty": 1,
    "toProductType": "CNC"
  }'
```


No response body. On successful completion of request, `202 Accepted` response status code will appear.

## Sample response for Convert Position API

`202 Accepted`. There is no response body.

Check the [Annexure](/api/v2/annexure#trading-api-error) for error codes.


### Request Body Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| dhanClientId | string | No | User specific identification generated by Dhan |
| fromProductType | enum | No | From Product type Values: `CNC`, `INTRADAY`, `MARGIN`. |
| exchangeSegment | enum | No | Exchange Segment (see Annexure) Values: `NSE_EQ`, `NSE_FNO`, `BSE_EQ`, `BSE_FNO`, `MCX_COMM`. |
| positionType | enum | No | Position to convert Values: `LONG`, `SHORT`, `CLOSED`. |
| securityId | string | No | Exchange standard ID for each scrip. refer here |
| convertQty | int | No | Quantity to convert |
| toProductType | enum | No | To Product type Values: `CNC`, `INTRADAY`, `MARGIN`. |


### Status Codes

| Code | Description |
|------|-------------|
| 202 | Conversion accepted |


### Example Request

```bash
curl -X POST https://api.dhan.co/v2/positions/convert \
  -H "access-token: <your-access-token>" \
  -H "Content-Type: application/json"
```
