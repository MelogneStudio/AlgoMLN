# Slice Order

`POST` https://api.dhan.co/v2/orders/slicing

Place order with slicing for quantities exceeding freeze limit.

Place an F&O order larger than the exchange freeze limit in one request. Dhan splits the quantity into several orders within the limit and places them for you, so you don't have to slice and send each one yourself.

The request body is the same as [Place Order](/api/v2/orders/place-order). The response returns the `orderId` and `orderStatus` for the slices placed, which you can track in the [order book](/api/v2/orders/get-orders).

**Before you start with Slice Order API**

1. Generate an access token on [web.dhan.co](https://web.dhan.co) under **Profile → Trading & Data APIs**.
2. Whitelist your [static IP](/api/v2/authentication/set-ip). Orders only go through from it.
3. Look up the F&O contract's `securityId` and `exchangeSegment` in the [instrument list](/api/v2/instruments).

> **NOTICE:** Order Placement, Modification and Cancellation APIs requires Static IP whitelisting - [refer here](/api/v2/authentication#setup-static-ip)

## Sample request for Slice Order API

A market buy of 1 share of Vodafone Idea (`securityId` 14366) on NSE. Replace the client ID and access token with your own.

```bash title="cURL"
curl --request POST \
  --url https://api.dhan.co/v2/orders/slicing \
  --header 'Content-Type: application/json' \
  --header 'access-token: <your-access-token>' \
  --data '{
    "dhanClientId": "<your-client-id>",
    "correlationId": "dhan-docs-test",
    "transactionType": "BUY",
    "exchangeSegment": "NSE_EQ",
    "productType": "CNC",
    "orderType": "MARKET",
    "validity": "DAY",
    "securityId": "14366",
    "quantity": 1,
    "disclosedQuantity": 0,
    "price": 0,
    "triggerPrice": 0,
    "afterMarketOrder": false
  }'
```


## Sample response for Slice Order API

```json title="200 OK"
[
  {
    "orderId": "112111182198",
    "orderStatus": "TRANSIT"
  }
]
```

Check the [Annexure](/api/v2/annexure#trading-api-error) for error codes.


### Request Body Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| dhanClientId | string | Yes | User specific identification generated by Dhan |
| correlationId | string | No | User/partner generated id for tracking back Constraints: Max 30 chars, Allowed: a-zA-Z0-9-_. |
| transactionType | enum | Yes | The trading side of transaction Values: `BUY`, `SELL`. |
| exchangeSegment | enum | Yes | Exchange Segment (see Annexure) Values: `NSE_EQ`, `NSE_FNO`, `NSE_COMM`, `BSE_EQ`, `BSE_FNO`, `MCX_COMM`. |
| productType | enum | Yes | Product type (see Annexure) Values: `CNC`, `INTRADAY`, `MARGIN`, `MTF`. |
| orderType | enum | Yes | Order Type Values: `LIMIT`, `MARKET`, `STOP_LOSS`, `STOP_LOSS_MARKET`. |
| validity | enum | Yes | Validity of Order Values: `DAY`, `IOC`. |
| securityId | string | No | Exchange standard ID for each scrip. refer here |
| quantity | int | Yes | Number of shares for the order |
| disclosedQuantity | int | No | Number of shares visible (keep >30% of quantity) |
| price | float | Yes | Price at which order is placed |
| triggerPrice | float | No | Price at which order is triggered (for SL-M & SL-L) |
| afterMarketOrder | boolean | No | Flag for orders placed after market hours |
| amoTime | enum | No | Timing for after market order (see Annexure) Values: `PRE_OPEN`, `OPEN`, `OPEN_30`, `OPEN_60`. |
| algoId | string | No | Algo ID |


### Response Fields

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| orderId | string | No | Order specific identification generated by Dhan |
| orderStatus | enum string | No | Last updated order status [see annexure](/api/v2/annexure#order-status) Values: `TRANSIT`, `PENDING`, `REJECTED`, `CANCELLED`, `PART_TRADED`, `TRADED`, `EXPIRED`, `MODIFIED`, `TRIGGERED`. |


### Status Codes

| Code | Description |
|------|-------------|
| 200 | Sliced orders placed |


### Example Request

```bash
curl -X POST https://api.dhan.co/v2/orders/slicing \
  -H "access-token: <your-access-token>" \
  -H "Content-Type: application/json"
```
