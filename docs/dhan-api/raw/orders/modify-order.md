# Modify Order

`PUT` https://api.dhan.co/v2/orders/{orderId}

Modify a pending order.

Change a pending order without cancelling it. Send the `orderId` with the new price, quantity, order type, validity, disclosed quantity or trigger price. Only orders that are still pending can be modified.

The response returns the `orderId` and its `orderStatus`. The change applies once the exchange accepts it, so confirm it with [Get Order by ID](/api/v2/orders/get-order-by-id) or the [Live Order Update](/api/v2/order-update) feed.

**Before you start with Modify Order API**

1. Generate an access token on [web.dhan.co](https://web.dhan.co) under **Profile → Trading & Data APIs**.
2. Whitelist your [static IP](/api/v2/authentication/set-ip). Orders only go through from it.
3. Copy the `orderId` of a pending order from the [order book](/api/v2/orders/get-orders) and enter it under Path Parameters below.

> **NOTICE:** Order Placement, Modification and Cancellation APIs requires Static IP whitelisting - [refer here](/api/v2/authentication#setup-static-ip)

## Sample request for Modify Order API

Change a pending order to a 1-share LIMIT order at ₹12.90. Replace the client ID, order ID (`112111182198` here) and access token with your own.

```bash title="cURL"
curl --request PUT \
  --url https://api.dhan.co/v2/orders/112111182198 \
  --header 'Content-Type: application/json' \
  --header 'access-token: <your-access-token>' \
  --data '{
    "dhanClientId": "<your-client-id>",
    "orderId": "112111182198",
    "orderType": "LIMIT",
    "quantity": 1,
    "price": 12.9,
    "disclosedQuantity": 0,
    "triggerPrice": 0,
    "validity": "DAY",
    "legName": "NA"
  }'
```


## Sample response for Modify Order API

```json title="200 OK"
{
  "orderId": "112111182198",
  "orderStatus": "TRANSIT"
}
```

Check the [Annexure](/api/v2/annexure#trading-api-error) for error codes.


### Path Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| order-id | string | Yes | Order specific identification generated by Dhan |


### Request Body Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| dhanClientId | string | Yes | User specific identification generated by Dhan |
| orderId | string | Yes | Order specific identification generated by Dhan |
| orderType | enum | Yes | Order Type Values: `LIMIT`, `MARKET`, `STOP_LOSS`, `STOP_LOSS_MARKET`. |
| quantity | int | No | Quantity to be modified |
| price | float | No | Price to be modified |
| disclosedQuantity | int | No | Number of shares visible (keep >30% of quantity) |
| triggerPrice | float | No | Price at which order is triggered (for SL-M & SL-L) |
| validity | enum | Yes | Validity of Order Values: `DAY`, `IOC`. |
| legName | enum | No | Leg name for Super Order modification Values: `ENTRY_LEG`, `STOP_LOSS_LEG`, `TARGET_LEG`, `NA`. |


### Response Fields

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| orderId | string | No | Order specific identification generated by Dhan |
| orderStatus | enum string | No | Last updated order status [see annexure](/api/v2/annexure#order-status) Values: `TRANSIT`, `PENDING`, `REJECTED`, `CANCELLED`, `PART_TRADED`, `TRADED`, `EXPIRED`, `MODIFIED`, `TRIGGERED`. |


### Status Codes

| Code | Description |
|------|-------------|
| 200 | Order modified |


### Example Request

```bash
curl -X PUT https://api.dhan.co/v2/orders/{orderId} \
  -H "access-token: <your-access-token>" \
  -H "Content-Type: application/json"
```
