# Cancel Order

`DELETE` https://api.dhan.co/v2/orders/{order-id}

Cancel a pending order.

The response returns the `orderId` and its `orderStatus`. Confirm the cancellation with [Get Order by ID](/api/v2/orders/get-order-by-id) or the [Live Order Update](/api/v2/order-update) feed.

**Before you start with Cancel Order API**

1. Generate an access token on [web.dhan.co](https://web.dhan.co) under **Profile → Trading & Data APIs**.
2. Whitelist your [static IP](/api/v2/authentication/set-ip). Orders only go through from it.
3. Copy the `orderId` of a pending order from the [order book](/api/v2/orders/get-orders) and enter it under Path Parameters below.

> **NOTICE:** Order Placement, Modification and Cancellation APIs requires Static IP whitelisting - [refer here](/api/v2/authentication#setup-static-ip)

## Sample request for Cancel Order API

Cancel a pending order. There is no request body. Replace the order ID (`112111182198` here) and access token with your own.

```bash title="cURL"
curl --request DELETE \
  --url https://api.dhan.co/v2/orders/112111182198 \
  --header 'access-token: <your-access-token>'
```


## Sample response for Cancel Order API

```json title="202 Accepted"
{
  "orderId": "112111182198",
  "orderStatus": "CANCELLED"
}
```

Check the [Annexure](/api/v2/annexure#trading-api-error) for error codes.


### Path Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| order-id | string | Yes | Order ID of the Order being cancelled |


### Response Fields

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| orderId | string | No | Order specific identification generated by Dhan |
| orderStatus | enum string | No | Last updated status of the order Values: `TRANSIT`, `PENDING`, `REJECTED`, `CANCELLED`, `TRADED`. |


### Status Codes

| Code | Description |
|------|-------------|
| 200 | Order cancelled |


### Example Request

```bash
curl -X DELETE https://api.dhan.co/v2/orders/{order-id} \
  -H "access-token: <your-access-token>"
```
