# Get Fund Limits

`GET` https://api.dhan.co/v2/fundlimit

Retrieve available balance and fund limits.

Get all information of your trading account like balance, margin utilised, collateral, etc.

Your **available balance** and margins: start-of-day limit, margin used, collateral from pledged shares and **withdrawable balance**.

**Before you start with Get Fund Limits API**

1. Generate an access token on [web.dhan.co](https://web.dhan.co) under **Profile → Trading & Data APIs**.
2. Paste it into the `access-token` field below.

## Sample request for Get Fund Limits API

Fetch your fund limits. Replace the access token with your own.

```bash title="cURL"
curl --request GET \
  --url https://api.dhan.co/v2/fundlimit \
  --header 'access-token: <your-access-token>'
```


## Sample response for Get Fund Limits API

```json title="200 OK"
{
  "dhanClientId": "1000000132",
  "availabelBalance": 25000.0,
  "sodLimit": 25000.0,
  "collateralAmount": 0.0,
  "receiveableAmount": 0.0,
  "utilizedAmount": 12.97,
  "blockedPayoutAmount": 0.0,
  "withdrawableBalance": 24987.03
}
```

Check the [Annexure](/api/v2/annexure#trading-api-error) for error codes.


### Response Fields

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| dhanClientId | string | No | User specific identification generated by Dhan |
| availabelBalance | float | No | Primary field to check the overall usable balance |
| sodLimit | float | No | Start of day limit |
| collateralAmount | float | No | Amount received against pledged shares |
| receiveableAmount | float | No | Any newly added funds or updated profit |
| utilizedAmount | float | No | Funds used for executing any trades |
| blockedPayoutAmount | float | No | Funds blocked for withdrawal |
| withdrawableBalance | float | No | Amount available to withdraw |


### Status Codes

| Code | Description |
|------|-------------|
| 200 | Fund limit details |


### Example Request

```bash
curl -X GET https://api.dhan.co/v2/fundlimit \
  -H "access-token: <your-access-token>"
```
