# Calculate Multi-Order Margin

`POST` https://api.dhan.co/v2/margincalculator/multi

Calculate combined margin for multiple orders with hedge benefits.

The Multi Order Margin Calculator API allows users to calculate margin requirements for multiple scripts in a single request, including span, exposure, equity, F&O, and commodity margins.

Note: Margin values returned are indicative and valid only for the current trading session.

**Before you start with Calculate Multi-Order Margin API**

1. Generate an access token on [web.dhan.co](https://web.dhan.co) under **Profile → Trading & Data APIs**.
2. Paste it into the `access-token` field below.
3. Add each order to `scripList`.

## Sample request for Calculate Multi-Order Margin API

Margin for buying 1 share of Vodafone Idea (`securityId` 14366) at ₹12.97. Add more objects to `scripList` to include more orders. Replace the client ID and access token with your own.

```bash title="cURL"
curl --request POST \
  --url https://api.dhan.co/v2/margincalculator/multi \
  --header 'Content-Type: application/json' \
  --header 'access-token: <your-access-token>' \
  --data '{
    "dhanClientId": "<your-client-id>",
    "includePosition": "false",
    "includeOrder": "false",
    "scripList": [
      {
        "exchangeSegment": "NSE_EQ",
        "transactionType": "BUY",
        "quantity": 1,
        "productType": "CNC",
        "securityId": "14366",
        "price": 12.97,
        "triggerPrice": 0
      }
    ]
  }'
```


## Sample response for Calculate Multi-Order Margin API

```json title="200 OK"
{
  "clientId": "1000000132",
  "totalMargin": 12.97,
  "spanMargin": 0.0,
  "exposure": 0.0,
  "equityMargin": 12.97,
  "foMargin": 0.0,
  "commodity": 0.0,
  "currency": 0.0
}
```

Check the [Annexure](/api/v2/annexure#trading-api-error) for error codes.
