# Trader's Control

Global Stocks Trader's Control: US market open/closed status and session times.

The Global Stocks trader's control API lets you check the current market status.

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | [`/globalstocks/marketstatus`](/api/v2/global-stocks/get-market-status) | Retrieve the current trading status and session timing for the US stock market. |
