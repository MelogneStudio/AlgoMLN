# Portfolio & Positions

Global Stocks Portfolio & Positions: your US stock holdings with cost, value and gain.

The Global Stocks portfolio API lets you retrieve your current holdings.

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | [`/globalstocks/holdings`](/api/v2/global-stocks/get-holdings) | Retrieve the authenticated user's current US stock holdings and holding-level details. |
