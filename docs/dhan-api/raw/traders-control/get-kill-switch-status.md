# Kill Switch Status

`GET` https://api.dhan.co/v2/killswitch

Check whether kill switch is active for the current trading day.

The API allows you to check kill switch status for your account - whether it is active for the current trade or not.

**Before you start with Kill Switch Status API**

1. Generate an access token on [web.dhan.co](https://web.dhan.co) under **Profile → Trading & Data APIs**.
2. Paste it into the `access-token` field below.

## Sample request for Kill Switch Status API

Fetch the kill switch status. Replace the access token with your own.

```bash title="cURL"
curl --request GET \
  --url https://api.dhan.co/v2/killswitch \
  --header 'access-token: <your-access-token>'
```


## Sample response for Kill Switch Status API

```json title="200 OK"
{
  "dhanClientId": "1000000132",
  "killSwitchStatus": "ACTIVE"
}
```

Check the [Annexure](/api/v2/annexure#trading-api-error) for error codes.


### Response Fields

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| dhanClientId | string | No | User specific identification generated by Dhan |
| killSwitchStatus | string | No | Status of Kill Switch Values: `ACTIVE`, `INACTIVE`. |


### Status Codes

| Code | Description |
|------|-------------|
| 200 | Current kill switch status |
| 401 | Unauthorized |


### Example Request

```bash
curl -X GET https://api.dhan.co/v2/killswitch \
  -H "access-token: <your-access-token>"
```
