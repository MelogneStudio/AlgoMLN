# Configure P&L Based Exit

`POST` https://api.dhan.co/v2/pnlExit

Configure automatic exit rules based on cumulative profit or loss thresholds.

> **Note:** The configured P&L based exit remains active for the current day and is reset at the end of the trading session.

**Before you start with Configure P&L Based Exit API**

1. Generate an access token on [web.dhan.co](https://web.dhan.co) under **Profile → Trading & Data APIs**.
2. Whitelist your [static IP](/api/v2/authentication/set-ip). Orders only go through from it.
3. Set `profitValue` and `lossValue` in rupees and pick the product types to cover.

> **NOTICE:** Order Placement, Modification and Cancellation APIs requires Static IP whitelisting - [refer here](/api/v2/authentication#setup-static-ip)

## Sample request for Configure P&L Based Exit API

Exit intraday positions at ₹1,500 profit or ₹500 loss, without the kill switch. Replace the client ID and access token with your own.

```bash title="cURL"
curl --request POST \
  --url https://api.dhan.co/v2/pnlExit \
  --header 'Content-Type: application/json' \
  --header 'access-token: <your-access-token>' \
  --data '{
    "dhanClientId": "<your-client-id>",
    "profitValue": 1500,
    "lossValue": 500,
    "productType": [
      "INTRADAY"
    ],
    "enableKillSwitch": false
  }'
```


| Parameter | Data Type | Description |
|-----------|-----------|-------------|
| pnlExitStatus | string | P&L based exit status: `ACTIVE` `INACTIVE` |
| message | string | Status of Conditional Trigger |

## Sample response for Configure P&L Based Exit API

```json title="200 OK"
{
  "pnlExitStatus": "ACTIVE",
  "message": "P&L based exit configured successfully"
}
```

Check the [Annexure](/api/v2/annexure#trading-api-error) for error codes.


### Request Body Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| dhanClientId | string | No | User specific identification generated by Dhan |
| profitValue | float | No | Maximum portfolio-level profit to trigger exit |
| lossValue | float | No | Maximum portfolio-level loss to trigger exit |
| productType[0] | enum | No | Product types applicable (array): INTRADAY or DELIVERY Values: `INTRADAY`, `DELIVERY`. |
| enableKillSwitch | boolean | No | Indicates if kill switch is enabled (true or false) |


### Status Codes

| Code | Description |
|------|-------------|
| 200 | P&L exit configured |
| 401 | Unauthorized |


### Example Request

```bash
curl -X POST https://api.dhan.co/v2/pnlExit \
  -H "access-token: <your-access-token>" \
  -H "Content-Type: application/json"
```
