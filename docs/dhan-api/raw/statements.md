# Statement

Statement: ledger report and trade history with brokerage and charges, using the Dhan API.

This set of APIs retreives all your trade and ledger details to help you summarise and analyse your trades.

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | [`/ledger`](/api/v2/statements/get-ledger-report) | Retrieve Trading Account debit and credit details |
| GET | [`/trades/`](/api/v2/statements/get-trade-history) | Retrieve historical trade data |
