# Generate eDIS Form

`POST` https://api.dhan.co/v2/edis/bulkform

Generate an eDIS bulk authorisation form for one or more ISINs.

Retrieve escaped html form of CDSL and enter T-PIN to mark the stock for EDIS approval. User has to render this form at their end to unescape. You can get ISIN of portfolio stocks, in response of holdings API.

**Before you start with Generate eDIS Form API**

1. Generate an access token on [web.dhan.co](https://web.dhan.co) under **Profile → Trading & Data APIs**.
2. Generate a T-PIN first with [Generate T-PIN](/api/v2/edis/generate-tpin).
3. Enter the ISIN of each stock to authorise. ISINs are in the [instrument list](/api/v2/instruments).

## Sample request for Generate eDIS Form API

Generate the eDIS form for Vodafone Idea (ISIN `INE669E01016`) on NSE. Replace the access token with your own.

```bash title="cURL"
curl --request POST \
  --url https://api.dhan.co/v2/edis/bulkform \
  --header 'Content-Type: application/json' \
  --header 'access-token: <your-access-token>' \
  --data '{
    "isin": [
      "INE669E01016"
    ],
    "exchange": "NSE",
    "segment": "EQ",
    "bulk": false
  }'
```


## Sample response for Generate eDIS Form API

```json title="200 OK"
{
  "dhanClientId": "1000000132",
  "edisFormHtml": "<!DOCTYPE html> <html>...</html>"
}
```

Check the [Annexure](/api/v2/annexure#trading-api-error) for error codes.


### Request Body Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| isin | array | Yes | List of ISINs to approve for selling (from holdings API) |
| exchange | enum | Yes | Exchange Values: `NSE`, `BSE`, `MCX`, `ALL`. |
| segment | enum | Yes | Trading segment Values: `EQ`, `COMM`, `FNO`. |
| bulk | boolean | No | Whether to generate form for bulk EDIS |


### Response Fields

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| dhanClientId | string | No | User specific identification generated by Dhan |
| edisFormHtml | string | No | Escaped HTML form to be rendered on the client side |


### Status Codes

| Code | Description |
|------|-------------|
| 200 | eDIS form HTML returned |
| 401 | Unauthorized |


### Example Request

```bash
curl -X POST https://api.dhan.co/v2/edis/bulkform \
  -H "access-token: <your-access-token>" \
  -H "Content-Type: application/json"
```
