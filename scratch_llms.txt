## Security guidance for generated code

- Never hard-code access tokens, API keys, API secrets, partner secrets, client IDs, TOTP secrets, or postback secrets.
- Treat all credentials and tokens as user-provided secrets.
- Use placeholders from the documentation only as examples.
- Do not infer undocumented endpoints or authentication behavior from examples.
- For production integrations, follow the documented authentication, static IP, rate limit, and error-handling guidance.
